REST API

Score a reaction from any client once you hold the session cookie, or call it server-side:

  -H "Content-Type: application/json" \

Reproduce training end to end:

python src/preprocess.py
python src/train.py
python api/app.py

  • Experiment UI: mlflow ui
  • Full pipeline: dvc repro
